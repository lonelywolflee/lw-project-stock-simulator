# Frontend

React 19 + TypeScript + Vite 기반 SPA 대시보드. shadcn/ui, Tailwind CSS v4, TanStack Query v5, Recharts를 사용한다.

## 사전 요구사항

- Node.js >= 20
- npm

## 빌드

```bash
npm install
```

## 실행

```bash
npm run dev  # :5173
```

## 검증

```bash
npx tsc --noEmit    # 타입 체크
npx vite build      # 빌드 체크
npm run lint        # 린트
```
